# Food Journal - Community Edition

A simple JavaFX application to log meals and calculate daily calorie intake.

## 🚀 Setup
1. Clone the repository.
2. Ensure JavaFX is installed and configured.
3. Run `foodJournalMain.java`.

## 🧩 Features
- Input nutrition facts (Fat, Carbs, Protein, Sugar).
- Automatic calorie calculation.
- Scrollable meal log.
- Daily calorie counter with reset option.

## 🤝 Contributing
- Keep file paths relative and cross-platform.
- Document new features with clear comments.
- Avoid personal identifiers in code or comments.
- Extend functionality by adding new nutrition fields or export options.

## 🛠️ Future Ideas
- Export logs to CSV/JSON.
